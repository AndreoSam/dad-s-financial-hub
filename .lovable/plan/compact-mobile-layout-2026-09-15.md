# Compact Mobile Layout

## Goal
Make the existing FD tracker denser and easier to scan and use on phones without changing its desktop layout or deposit calculations.

## Changes
- Compress the header and use icon-sized mobile actions while keeping clear accessible labels.
- Show the four totals in a compact two-column grid on phones.
- Place search and filters in a space-efficient mobile arrangement.
- Tighten each mobile deposit row, preserving all key amounts, dates, status, edit, and delete actions.
- Make the add/edit form denser on phones with compact spacing and paired fields where they remain readable.
- Keep tablet and desktop presentation unchanged where practical.

## Validation
- Check the phone preview for clipping, overlap, horizontal scrolling, and readable controls.
- Confirm the app still builds successfully and the add/edit interactions remain available.
